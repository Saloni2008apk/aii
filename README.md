
# 🎃 SpookyStudy AI

SpookyStudy AI is a beginner-friendly AI study assistant
that turns difficult topics into simple notes, explanations,
and quiz questions.

## 💡 Problem

Students sometimes find technical topics difficult to
understand and need simple revision material.

## 🚀 Solution

SpookyStudy AI helps students:
- Generate simple study notes
- Understand topics through everyday analogies
- Practice multiple-choice questions
- Revise concepts in less time

## ✨ Features

- Halloween-inspired interface
- Beginner-friendly explanations
- Notes, quizzes, and explanations
- Demo mode without an API key
- Gemini API integration
- Copy notes to the clipboard
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML — website structure
- CSS — design and layout
- JavaScript — functionality
- Gemini API — AI-generated study content

## ▶️ How to Run

1. Download or clone this repository.
2. Keep index.html, style.css, and script.js together.
3. Open index.html in your browser.
4. Click "Try Demo" to test the website.
5. For AI generation, configure Gemini API access.

## 🔐 Security

This is a learning prototype. Never upload API keys
to GitHub. A public version should use a secure
backend to protect credentials.

## ⚠️ Limitations

AI-generated answers may contain mistakes.
Always verify important academic information.

## 🎯 Project Goal

Make studying easier, more interactive, and fun
for students through AI.
